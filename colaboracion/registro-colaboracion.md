# Registro de colaboración

## Objetivo
Documentar las actividades reales de revisión entre compañeros, los aportes de cada participante y los aprendizajes obtenidos en el proyecto de pruebas de API.

## Actividad propuesta
Revisar en conjunto el caso API-003:

`GET /posts/9999`

Resultado observado inicialmente: `404 Not Found` con cuerpo `{}`. La solicitud no tenía aserciones automáticas en la ejecución registrada.

### Pasos sugeridos
1. Cada participante ejecuta la solicitud de manera independiente en Postman.
2. Se comparan el código HTTP y el cuerpo de respuesta.
3. Se consulta la documentación para acordar el resultado esperado.
4. Se decide si debe añadirse una validación automática para el código 404.
5. Se actualizan los casos de prueba con la conclusión conjunta.
